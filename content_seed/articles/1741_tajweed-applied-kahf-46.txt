آية قصيرة في الموازنة بين الفاني والباقي. اقرأ معها [تفسير آية «المال والبنون زينة الحياة الدنيا»](/blog/tafsir-ayah-al-malu-wal-banuna-zina/).

## الآية
﴿ٱلۡمَالُ وَٱلۡبَنُونَ زِينَةُ ٱلۡحَيَوٰةِ ٱلدُّنۡيَاۖ وَٱلۡبَٰقِيَٰتُ ٱلصَّـٰلِحَٰتُ خَيۡرٌ عِندَ رَبِّكَ ثَوَابٗا وَخَيۡرٌ أَمَلٗا﴾ [الكهف: 46].

## الأحكام
| الموضع | الحكم |
|---|---|
| ﴿ٱلۡمَالُ﴾ و﴿وَٱلۡبَنُونَ﴾ | لام **قمرية** |
| ﴿ٱلۡحَيَوٰةِ﴾ | لام **قمرية**، وتُقرأ الواو المرسومة **ألفًا** |
| ﴿ٱلدُّنۡيَاۖ﴾ | لام **شمسية**، و**إظهار مطلق** للنون |
| ﴿وَٱلۡبَٰقِيَٰتُ﴾ | لام **قمرية**، والقاف **مفخمة** |
| ﴿ٱلصَّـٰلِحَٰتُ﴾ | لام **شمسية**، والصاد **مفخمة** |
| ﴿خَيۡرٌ عِندَ﴾ | **إظهار حلقي** عند العين |
| ﴿عِندَ﴾ | **إخفاء** عند الدال |
| ﴿رَبِّكَ﴾ | الراء المفتوحة **مفخمة** |
| ﴿ثَوَابٗا وَخَيۡرٌ﴾ | **إدغام بغنة ناقص** |
| ﴿وَخَيۡرٌ أَمَلٗا﴾ | **إظهار حلقي** عند الهمزة |
| ﴿أَمَلٗا﴾ | عند الوقف **مد عوض** |

## لطيفة
- ﴿خَيۡرٌ﴾ تكررت مرتين، وبعدها في الموضعين **إظهار حلقي**: الأول عند العين، والثاني عند الهمزة.
