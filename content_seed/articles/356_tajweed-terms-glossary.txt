هذا معجم مرجعي مختصر، ارجع إليه كلما سمعت مصطلحًا لا تعرفه. وقد رتبناه حسب الأبواب.

## أساسيات
| المصطلح | التعريف |
|---|---|
| التجويد | إعطاء كل حرف حقه ومستحقه من المخرج والصفات والأحكام |
| المخرج | موضع خروج الحرف |
| الصفة | كيفية نطق الحرف عند خروجه |
| اللحن الجلي | خطأ ظاهر يغير الحرف أو الحركة |
| اللحن الخفي | خطأ في كمال الأداء كترك الغنة |
| التلقي | أخذ القراءة من فم المعلم |

## النون الساكنة والتنوين
| المصطلح | التعريف | مثال |
|---|---|---|
| الإظهار الحلقي | نطق النون واضحة قبل حروف الحلق | ﴿مَنۡ ءَامَنَ﴾ |
| الإدغام بغنة | إدخال النون في «ينمو» مع غنة | ﴿مَن يَعۡمَلۡ﴾ |
| الإدغام بغير غنة | إدخال النون في اللام والراء | ﴿مِن رَّبِّهِمۡ﴾ |
| الإقلاب | قلب النون ميمًا قبل الباء | ﴿مِنۢ بَعۡدِ﴾ |
| الإخفاء | حال بين الإظهار والإدغام مع غنة | ﴿كُنتُمۡ﴾ |
| الإظهار المطلق | إظهار النون قبل الواو والياء في كلمة واحدة | ﴿ٱلدُّنۡيَا﴾ |

## الميم الساكنة
| المصطلح | التعريف |
|---|---|
| الإخفاء الشفوي | إخفاء الميم قبل الباء بغنة |
| الإدغام الشفوي | إدغام الميم في الميم بغنة |
| الإظهار الشفوي | إظهار الميم قبل بقية الحروف |

## المدود
| المصطلح | التعريف |
|---|---|
| المد الطبيعي | حركتان بلا سبب |
| المتصل | حرف مد بعده همزة في كلمته |
| المنفصل | حرف مد في آخر كلمة وهمزة في أول التالية |
| البدل | همزة بعدها حرف مد |
| العارض للسكون | حرف مد بعده حرف سُكّن للوقف |
| اللين | واو أو ياء ساكنة بعد فتح |
| العوض | ألف عن تنوين الفتح وقفًا |
| الصلة | مد هاء الضمير بين متحركين |
| اللازم | حرف مد بعده سكون أصلي |
| الحرفي | مد في أسماء الحروف المقطعة |

## الصفات والأحكام
| المصطلح | التعريف |
|---|---|
| القلقلة | اضطراب المخرج في «قطب جد» الساكنة |
| الغنة | صوت من الخيشوم في النون والميم |
| التفخيم | امتلاء الفم بصدى الحرف |
| الترقيق | نحول الحرف |
| الاستعلاء | ارتفاع أقصى اللسان |
| الإطباق | انطباق اللسان على الحنك |
| الهمس | جريان النفس |
| الجهر | انحباس النفس |
| الشدة | انحباس الصوت |
| التكرير | قابلية الراء للارتعاد |

## الوقف والابتداء
| المصطلح | التعريف |
|---|---|
| الوقف | قطع الصوت مع التنفس بنية الاستئناف |
| السكت | قطع الصوت بلا تنفس |
| القطع | إنهاء القراءة |
| الروم | النطق ببعض الحركة عند الوقف |
| الإشمام | ضم الشفتين بعد الإسكان بلا صوت |
| وقف المعانقة | موضعان إذا وُقف على أحدهما لم يوقف على الآخر |
