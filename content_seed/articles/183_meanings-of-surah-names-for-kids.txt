كثير من سور جزء عمّ سُميت **بكلمة من آياتها**، غالبًا من أولها. وحين يعرف الطفل معنى اسم السورة، يتذكرها ويتذكر موضوعها. وهذه معاني الأسماء ببساطة.

## من النبأ إلى المطففين
| السورة | معنى الاسم |
|---|---|
| **النبأ** | الخبر العظيم، وهو يوم القيامة |
| **النازعات** | الملائكة التي تنزع الأرواح |
| **عبس** | قطّب وجهه، في قصة الصحابي الكفيف |
| **التكوير** | لفّ الشمس وذهاب ضوئها يوم القيامة |
| **الانفطار** | انشقاق السماء |
| **المطففين** | الذين ينقصون الكيل والميزان |

## من الانشقاق إلى البلد
| السورة | معنى الاسم |
|---|---|
| **الانشقاق** | انشقاق السماء |
| **البروج** | منازل النجوم العظيمة في السماء |
| **الطارق** | النجم الذي يظهر ليلًا ﴿ٱلنَّجۡمُ ٱلثَّاقِبُ﴾ |
| **الأعلى** | من أسماء الله: العالي فوق كل شيء |
| **الغاشية** | يوم القيامة، لأنه يغشى الناس بأهواله |
| **الفجر** | أول ضوء الصباح |
| **البلد** | مكة المكرمة |

## من الشمس إلى الناس
| السورة | معنى الاسم |
|---|---|
| **الشمس، الليل، الضحى** | أقسم الله بها في أول كل سورة |
| **الشرح** | توسعة صدر النبي ﷺ |
| **التين** | الفاكهة المعروفة، أقسم الله بها |
| **العلق** | الدم المتجمد، أول خلق الإنسان |
| **القدر** | ليلة القدر العظيمة |
| **البينة** | الدليل الواضح، وهو النبي ﷺ |
| **الزلزلة** | اهتزاز الأرض يوم القيامة |
| **العاديات** | الخيل التي تجري بسرعة |
| **القارعة** | يوم القيامة، لأنه يقرع القلوب بالخوف |
| **التكاثر** | التفاخر بكثرة المال والأولاد |
| **العصر** | الزمن والوقت |
| **الهمزة** | الذي يعيب الناس ويغتابهم |
| **الفيل** | فيل جيش أبرهة |
| **قريش** | قبيلة النبي ﷺ |
| **الماعون** | الأشياء الصغيرة التي يستعيرها الجيران كالأواني |
| **الكوثر** | نهر في الجنة أعطاه الله للنبي ﷺ |
| **الكافرون** | الذين لا يؤمنون بالله |
| **النصر** | نصر الله وفتح مكة |
| **المسد** | الحبل المفتول من الليف |
| **الإخلاص** | توحيد الله وحده |
| **الفلق** | الصبح |
| **الناس** | البشر، فالله رب الناس وملكهم وإلههم |

## لاحظ مع طفلك
**أربع سور** أسماؤها من أسماء **يوم القيامة**: النبأ، والغاشية، والقارعة، والزلزلة. وأربع سور بأسماء **أوقات**: الفجر، والضحى، والعصر، والليل.
